Sesión 5 · prueba de hipótesis para una población

Probar una afirmación con datos: ¿rechazo H₀ o no?

Practica la prueba de hipótesis para una población: conceptos (H₀, H₁, errores tipo I y II, α), la prueba para la media (Z y t-Student), la proporción y la varianza (chi-cuadrado), con los 5 pasos de la sesión. Cada intento trae casos nuevos de 2026, tienes 20 minutos y el cronómetro te avisa cuando falten 3.

Lo que vas a usar
H₀ y H₁H₀ es la hipótesis de la igualdad (=, ≥ o ≤) y no se rechaza salvo que la muestra diga lo contrario. H₁ es la del investigador, lo que se quiere probar (<, > o ≠).
Errores y αError tipo I: rechazar H₀ siendo verdadera, con probabilidad α (el nivel de significación). Error tipo II: no rechazar H₀ siendo falsa, con probabilidad β. Potencia = 1 − β.
Región de rechazoDepende de H₁: «<» → cola izquierda; «>» → cola derecha; «≠» → dos colas, con α/2 en cada una. Si el estadístico cae en la RR, se rechaza H₀.
Los 5 pasos1) Hipótesis. 2) Nivel de significación α. 3) Estadístico de prueba. 4) Región de rechazo (valor crítico). 5) Conclusión en el contexto del problema.
Media, σ conocida (o n > 30 con s): Zcal = (x̄ − μ₀) / (σ/√n) [con s si n > 30] Media, σ desconocida, n ≤ 30: Tcal = (x̄ − μ₀) / (s/√n) ~ t(n−1) Proporción: Zcal = (p − π₀) / √( π₀(1 − π₀) / n ) Varianza: χ²cal = (n − 1)s² / σ₀² ~ χ²(n−1) Cola izquierda: Z₀ = Z de α (negativo), t₀ = −t(1−α ; r), χ²(α ; r). Cola derecha: Z de 1 − α, t(1−α ; r), χ²(1−α ; r). Bilateral: ±Z de 1 − α/2, ±t(1−α/2 ; r), χ²(α/2 ; r) y χ²(1−α/2 ; r). Z con 2 decimales; t y χ² críticos se leen tal cual de la tabla (3 decimales).
